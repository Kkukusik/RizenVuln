Помещайте доверенные CA в эту директорию (секретные ключи не коммитьте).
Она доступна в контейнерах как /app/certs. Например S3_CA_FILE=/app/certs/s3-ca.pem.
Для Docker mTLS identity PEM должен содержать сертификат и приватный ключ;
ограничьте доступ к файлу и предоставьте чтение UID 10001 контейнера.
